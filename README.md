# My Textbook Library

Reliable Streamlit PDF reader with no extra PDF Python dependencies.

## Upload these files to the ROOT of your GitHub repo

- app.py
- requirements.txt
- README.md

## Streamlit Cloud
- Branch: main
- Main file path: app.py

Then use Manage app -> Reboot app.

This version intentionally does not use PyMuPDF / fitz / Pillow.
